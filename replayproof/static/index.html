THE CORRECTNESS BOUNDARY

One database.
Nothing left between commits.

ReplayProof keeps the design small enough to inspect. Each accepted source event, cursor advancement, and projection change shares one PostgreSQL transaction.

01

Sequence is the contract.

Events beyond a missing number are stored, but have no effect on bars. Normal ingestion of the missing record unlocks the buffered prefix.

02

Time decides open and close.

Bars use UTC event time with sequence as a tie-break. Later sequences may revise earlier minutes, so every bar stays provisional.

03

The checker thinks independently.

A separate SQL aggregation compares every minute with the online Python projection. Exact expected and actual differences become persisted evidence.
